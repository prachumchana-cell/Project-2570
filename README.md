# ระบบจัดการโครงการก่อสร้าง ปีงบประมาณ 2570

เว็บแอปสำหรับติดตามโครงการก่อสร้าง งบประมาณ ความคืบหน้า และคณะกรรมการตรวจรับพัสดุ ใช้งานได้ทั้งแบบออนไลน์ (sync ผ่าน Supabase) และออฟไลน์ (เก็บใน localStorage ของเบราว์เซอร์)

## ฟีเจอร์

- **บันทึกโครงการ** — ชื่อโครงการ, แหล่งงบประมาณ, ปีงบประมาณ, สถานะ, ผู้รับเหมา, วงเงินงบประมาณ, ยอดเบิกจ่าย, ความคืบหน้า (%), รายละเอียดสถานที่/ขอบเขตงาน
- **คณะกรรมการตรวจรับพัสดุ** — เพิ่มรายชื่อ-ตำแหน่ง-ประเภทกรรมการได้ไม่จำกัดจำนวนต่อโครงการ
- **ค้นหา + กรอง + เรียงลำดับ** — ค้นจากชื่อโครงการ/แหล่งงบประมาณ/ผู้รับเหมา, กรองตามสถานะ, เรียงตามชื่อ/วันที่อัปเดต/งบประมาณ/ความคืบหน้า
- **แดชบอร์ดสรุป** — จำนวนโครงการทั้งหมด, ระหว่างดำเนินการ, เสร็จสิ้นแล้ว, งบประมาณรวม
- **สำรอง/นำเข้าข้อมูล** — ส่งออกเป็นไฟล์ `.json` และนำเข้ากลับได้
- **Cloud sync ผ่าน Supabase** — ถ้าเชื่อมต่อได้ ข้อมูลจะ sync ขึ้นฐานข้อมูลกลาง ถ้าเชื่อมต่อไม่ได้ (ไม่มีเน็ต/ตั้งค่าไม่ครบ) แอปจะสลับไปใช้ localStorage อัตโนมัติแบบไม่มีสะดุด — สถานะการเชื่อมต่อแสดงอยู่ข้างชื่อแอปด้านบน (🟢 ซิงค์กับฐานข้อมูล / 🔴 Offline)
- **รหัสผ่านทีม (PIN gate)** — กันคนนอกทีมเปิดแอปโดยบังเอิญ (ป้องกันเบื้องต้น ไม่ใช่ระบบล็อกอินเต็มรูปแบบ)

## เทคโนโลยีที่ใช้

- HTML/CSS/JavaScript ล้วน ไฟล์เดียวจบ ไม่มีขั้นตอน build
- [Supabase](https://supabase.com) — ฐานข้อมูล Postgres + REST API ผ่าน `@supabase/supabase-js` (โหลดจาก CDN)
- Google Fonts: Kanit, Sarabun, IBM Plex Mono
- `localStorage` เป็น fallback เมื่อไม่มีการเชื่อมต่อ Supabase

## การติดตั้ง

### 1. ตั้งค่าฐานข้อมูล Supabase

สร้างโปรเจกต์ใหม่ที่ [supabase.com](https://supabase.com) จากนั้นไปที่ **SQL Editor** แล้วรัน `construction_setup.sql` (แนบมาพร้อมโปรเจกต์นี้) เพื่อสร้างตาราง `construction_projects` และกฎการเข้าถึงข้อมูล (RLS)

> ⚠️ แอปนี้ไม่มีระบบล็อกอินผู้ใช้ ทุกคนที่ถือลิงก์แอปใช้ฐานข้อมูลชุดเดียวกัน กฎ RLS จึงเปิดกว้างให้อ่าน/เขียนได้ทุกคนที่มี anon key — เหมาะกับการใช้งานภายในทีมเท่านั้น **ห้ามเผยแพร่ลิงก์แอปหรือ anon key สู่สาธารณะ**

### 2. ใส่ค่าเชื่อมต่อในโค้ด

เปิด `index.html` หาบรรทัดนี้ในส่วน `<script>`:

```js
const SUPABASE_URL = "https://xxxxxx.supabase.co";
const SUPABASE_ANON_KEY = "...";
```

แทนที่ด้วยค่าจากโปรเจกต์ของคุณ (ดูได้ที่ Supabase → Settings → API)

### 3. ตั้งรหัสผ่านทีม

หาบรรทัดนี้ในโค้ด:

```js
const TEAM_PIN = '0000';
```

**เปลี่ยนเป็นรหัสของทีมคุณเองก่อนใช้งานจริง** ค่าเริ่มต้นเดาง่ายเกินไป ไม่ควรใช้จริง

### 4. อัปโหลดขึ้นโฮสติ้ง

อัปโหลด `index.html` ขึ้น static hosting ใดก็ได้ (เช่น GitHub Pages) ไม่ต้องมีไฟล์อื่นประกอบ

## โครงสร้างไฟล์

```
├── index.html              # ตัวแอปทั้งหมด (HTML/CSS/JS ในไฟล์เดียว)
├── construction_setup.sql  # สคริปต์สร้างตาราง + RLS สำหรับ Supabase
└── README.md
```

## หมายเหตุด้านความปลอดภัย

- รหัสผ่านทีม (PIN) เก็บอยู่ในโค้ดฝั่ง client ตรวจสอบแค่ใน localStorage ของเบราว์เซอร์ — ป้องกันคนเปิดเจอโดยบังเอิญได้ แต่ไม่ใช่การเข้ารหัสหรือระบบยืนยันตัวตนจริงจัง ผู้ที่ตั้งใจเปิดดูโค้ดจะเห็นรหัสได้
- ฐานข้อมูลเปิดให้เข้าถึงแบบไม่จำกัดสิทธิ์ (RLS `true` ทุก policy) เพราะไม่มีระบบล็อกอิน — ทุกคนที่มี URL แอปแก้ไข/ลบข้อมูลได้เท่ากันหมด ไม่มีการบันทึกว่าใครแก้ไขอะไร
- อยู่ระหว่างพัฒนาระบบล็อกอินแบบเต็มรูปแบบ (แยกบัญชีผู้ใช้แต่ละคน) เป็นขั้นต่อไป
